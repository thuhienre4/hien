# hien - Tool Học tập Công nghệ Kỹ thuật 🎓

Repository này chứa các công cụ giáo dục và học tập về công nghệ.

## 📚 Các công cụ có sẵn

### 1. Tool Học tập Công nghệ Kỹ thuật (TechLearningTool.py)

Một công cụ học tập tương tác được thiết kế cho học sinh học công nghệ kỹ thuật với các tính năng:

#### ✨ Tính năng chính:
- **📖 Học bài**: 6 chủ đề công nghệ với nội dung chi tiết
  - Cơ bản về Điện tử
  - Lập trình cơ bản
  - Mạng máy tính
  - Cơ học Robot
  - Internet of Things (IoT)
  - Trí tuệ nhân tạo (AI)

- **✏️ Kiểm tra**: Câu hỏi trắc nghiệm để đánh giá kiến thức
  - Mỗi chủ đề có 4 câu hỏi
  - Tự động chấm điểm
  - Hiển thị đáp án đúng

- **📊 Tiến độ**: Theo dõi quá trình học tập
  - Thống kê bài đã hoàn thành
  - Tổng điểm quiz
  - Hệ thống thành tích

#### 🚀 Cách sử dụng:

```bash
# Cài đặt dependencies
pip install -r requirements.txt

# Chạy tool học tập
streamlit run TechLearningTool.py
```

#### 📝 Nội dung học:
Mỗi bài học bao gồm:
- Lý thuyết cơ bản và nâng cao
- Ví dụ code thực tế
- Hình ảnh minh họa
- Tài liệu tham khảo
- Bài tập thực hành

#### 🎯 Đối tượng:
- Học sinh THPT quan tâm đến công nghệ
- Sinh viên ngành kỹ thuật
- Người mới bắt đầu tìm hiểu về công nghệ
